# Habit Builder Tracker v1.5.1

## Windows 8 Classic theme refinement

- Replaced Windows 95-style beveled controls with a flat, Metro-inspired Windows 8 desktop aesthetic.
- Applied Segoe UI typography, a cool light-gray application background, white surfaces, subtle separators, flat accent-color controls, square-edged navigation and clean dashboard tiles.
- Retained the existing `windows-classic` saved preference key so existing workspaces keep their selected theme without migration.
- Renamed the visible theme option to **Windows 8 Classic** and added a short description.
- Updated the service-worker cache and package version to 1.5.1.

This is a Windows 8-inspired presentation theme, not a Windows OS shell or Start screen replacement.
