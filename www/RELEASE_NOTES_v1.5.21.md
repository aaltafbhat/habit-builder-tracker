# Habit Builder Tracker v1.5.21 — Profile & Appearance Layout

## Improvements
- Rebalanced Profile & Appearance into side-by-side Profile/Security and Appearance cards on desktop.
- Moved Focus Timer Preferences into a full-width section beneath the two-column settings grid.
- Arranged timer durations and session feedback controls side by side for better use of horizontal space.
- Preserved all existing control IDs and settings persistence; no database migration is required.
- Added responsive stacking for tablet and mobile widths.
- Styled the new focus panels to match all seven visual styles and respect reduced-motion preferences.

## Installation
Extract the update into the existing project root and replace matching files. Do not clear IndexedDB or browser site data.
