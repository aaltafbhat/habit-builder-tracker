PRIVATE BY DESIGN

Encrypted Cloud Backup & Recovery

Encrypt backup files on this device before saving them to a cloud-synced folder.

Not configured

Encryption is enabled on this device. Recent backup entries can be restored without re-entering the passphrase on this browser.

Set a recovery passphrase before using a cloud-synced folder. Keep it in a password manager. Without it, encrypted backups cannot be recovered on another device.

Automatic backups are off. Sign-out backups remain enabled.

Cloud-folder workflow: install Google Drive for desktop or OneDrive and select its synced folder here. The app writes AES-256-GCM encrypted files into that folder; the sync client uploads them. This is not a direct Google or Microsoft account connection. Scheduled jobs run when the app opens or returns to the foreground, not while the browser is fully closed. If folder permission is unavailable, the app falls back to Downloads.

▣

Install Habit Builder Tracker

Install the workspace on a supported device for an app-like window and offline access to the app shell.

Checking installation support…

For installation and offline caching, open this app through localhost or a secure HTTPS address. IndexedDB remains local to this browser.

Recommended data protection routine

Download a backup weekly and before moving to another computer or browser. Keep the JSON file somewhere private. Restoring a backup replaces the app's current records with the records in that file.

Use the same workspace on your phone and laptop

This version stores records locally in each browser. It does not automatically synchronize changes between devices. To transfer your workspace, download a backup on the source device, securely move the JSON file to the other device, then choose Restore from Backup there. Restore replaces the destination device's current records, so download a safety backup on that device first. Avoid editing both devices separately until automatic cloud sync is added.
