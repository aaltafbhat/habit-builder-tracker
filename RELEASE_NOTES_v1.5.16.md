# Habit Builder Tracker v1.5.16 — Visual Design System & Motion Polish

- Replaced the primary Accent color block with six visual design languages: Neumorphism (Soft UI), Claymorphism, Skeuomorphism, Aurora UI, Flat Design 2.0 and Minimalism.
- Kept custom accent colors available in a collapsed secondary customization panel.
- Added a separate Bento Grid dashboard layout preference.
- Persisted visual style and dashboard layout per workspace and mirrored non-sensitive appearance metadata to the workspace registry.
- Added quick button/card micro-interactions, natural cubic-bezier easing and staggered IntersectionObserver-based scroll reveals.
- Reduce Motion overrides the reveal and hover animations. No external animation libraries or dependencies added.
- Default visual style: Flat Design 2.0. Bento Grid is enabled by default on the overview dashboard.
